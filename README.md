# IPA Impact Evaluation Readiness Checklist

An interactive web tool that helps program teams and partners assess whether a program is ready for a full-scale impact evaluation. The checklist is developed by [Innovations for Poverty Action (IPA)](https://poverty-action.org) and is freely available for use by any organization considering a rigorous program evaluation.

**Live tool:** [View the checklist](https://ipa-csri.github.io/impact-evaluation-checklist/) 

---

## What it does

The tool presents 10 yes/no questions across three sections — strategic foundation, program readiness, and evaluation feasibility. Upon completion, it returns a tiered readiness score with a list of items to address and recommended next steps.

---

## How to use it

Visit the live URL and work through the checklist as a team. For questions about your results or to connect with an IPA evaluation specialist, visit the [IPA Contact Us page](https://poverty-action.org/contact-us) and select "Partnering with IPA" in the Category field.

---

## How to edit the checklist

The recommended way to edit this tool is through a Claude project:

1. Download `index.html` from this repository
2. Upload it to a Claude project at [claude.ai](https://claude.ai)
3. Ask Claude to make the changes you need (e.g., update question text, adjust scoring, change results messaging)
4. Download the updated file Claude produces
5. Rename the downloaded file `index.html`, then go to this repository on GitHub, click **Add file > Upload files**, drag and drop the file, and click **Commit changes** to replace the existing version

GitHub Pages will publish the updated version within a few minutes.

---

## Deployment

The tool is a single self-contained HTML file with no external dependencies and no build process required.

To update the live site, replace `index.html` in this repository with the updated version. GitHub Pages will publish the change within a few minutes.
